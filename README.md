# 🐍 贪吃蛇 · 霓虹版 NEON SNAKE

霓虹风格的单文件网页贪吃蛇游戏，触屏与键盘皆可玩。

## 🎮 玩法

- 方向键 / WASD / 滑动屏幕控制蛇的移动
- 吃到发光食物得分 +10，每 50 分加速一档
- 撞墙或撞到自己游戏结束
- 空格加速 · P 暂停
- 最高分本地存档

## ✨ 特性

- 霓虹发光视觉（Canvas 渲染 + 粒子特效 + 得分飘字）
- Web Audio 合成音效（可开关）
- 响应式布局，手机端带虚拟方向键
- 单文件自包含，零依赖
